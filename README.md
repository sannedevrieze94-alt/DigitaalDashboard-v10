# Digitaal Dashboard Mensenhandel – Emmen

Prototype voor beleidsmatige monitoring van de gemeentelijke aanpak mensenhandel.

## Opzet
- **Openbare beleidslaag:** landelijke broncijfers, lokale context, trends en gemeentelijke KPI-voorstellen.
- **Contextkaart:** woonplaatsen en geografische context; nadrukkelijk geen incident- of hotspotkaart.
- **Demo-casuslaag:** uitsluitend fictieve records om een mogelijke afgeschermde gebruikersflow te demonstreren.

## Bronnen
De cijferpagina's gebruiken openbare informatie van onder meer de Nationaal Rapporteur, CoMensha, CBS en gemeente Emmen. Zie `bronnen.html` voor bronlinks en definities.

## Belangrijk
Dit prototype is **geen operationeel registratiesysteem**. De demo-login is client-side en biedt geen echte beveiliging. Gebruik deze repository niet voor persoonsgegevens, casuïstiek of andere gevoelige operationele informatie.
